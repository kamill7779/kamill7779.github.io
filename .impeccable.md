# Impeccable Design Context

## Design Context

### Users
- **Primary**: Hiring managers and recruiters evaluating technical competence — they scan quickly and look for authority signals
- **Secondary**: Fellow engineers seeking technical solutions, architecture ideas, and interesting perspectives
- **Tertiary**: Self — documenting learnings and building a personal knowledge archive
- **Context**: Visitors arrive from GitHub, social links, or search. They need to quickly gauge competence, then optionally dive deep into content. The blog must work as both portfolio and knowledge-sharing platform.

### Brand Personality
**Three words**: 简约 (Minimal) · 高级感 (Premium) · 现代感 (Modern)

- Understated competence — nothing flashy but clearly well-crafted
- Editorial sophistication with a technical edge
- Bilingual (Chinese + English) with seamless language integration
- Confident restraint — every element earns its place

### Emotional Goals
- **设计感** (Design-conscious): Visitors should notice the intentional design without it distracting from content
- **新颖但简约** (Novel but simple): Fresh visual ideas that never clutter or overwhelm
- **内容和谐** (Content harmony): Design serves content — typography, spacing, and color create a comfortable reading environment where the words are always the star

### Aesthetic Direction
- **Visual tone**: Monochromatic MD3 palette (gray-scale primary with warm undertones), generous whitespace, editorial asymmetric grids
- **Typography-first**: Inter for body/headlines, LXGW WenKai for Chinese, Fira Code for code — hierarchy through weight and size contrast, not color
- **Layout**: Asymmetric editorial grids (1:2 ratios), sticky sidebars, year-grouped archives — magazine-inspired but web-native
- **Theme**: Both light and dark mode — system-respecting, with warm dark (#0c0a09) and cool light (#f9f9fb)
- **Anti-patterns**: No bright accent colors, no gradients, no decorative illustrations, no playful/cartoon elements, no cluttered layouts

### Design Principles

1. **Content is king** — Every design decision exists to make reading and understanding easier. Decorations that don't serve comprehension are removed.

2. **Restrained sophistication** — Premium feel comes from precision (exact spacing, deliberate typography, consistent rhythms), not from adding more. Less, but better.

3. **Quiet confidence** — The design should feel inevitable, like it couldn't have been any other way. No need to shout — competence speaks through craft.

4. **Harmonious bilingualism** — Chinese and English must coexist naturally. Typography, spacing, and layout must feel equally considered for both languages.

5. **Modern craft** — Use contemporary patterns (MD3 tokens, CSS grid, subtle motion, backdrop blur) to create something that feels current without chasing trends.

### Technical Design Tokens Reference
- **Colors**: Full MD3 semantic token system (see `css/tailwind.css`)
- **Fonts**: Inter (body/headline), LXGW WenKai (Chinese), JetBrains Mono (labels), Fira Code (code)
- **Grid**: Editorial 1:2 asymmetric grid (`.editorial-grid`), 12-column layout for article detail
- **Spacing**: 8rem between major sections, 4rem between items, 2rem card padding, generous vertical rhythm
- **Motion**: 600ms ease-out transitions, 20px translateY for fade-ins, subtle hover effects
- **Border radius**: Minimal (0.125rem default) — sharp, editorial feel
- **Icons**: Material Symbols Outlined
